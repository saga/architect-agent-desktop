# 本地项目工作区

## 使用方式

主工具栏提供“打开工作区”入口。选择本机项目目录后，当前目录名称会显示在工具栏和 Agent 面板中；再次选择其他目录即可切换。选中的目录保存在应用本机用户数据目录，重启后自动恢复。

工作区不是浏览器布局的一部分。切换项目不会改变 Browser/Agent 面板、Dock、Tab Group 或 Layout Engine 的状态。

## Agent 行为

- CodeBuddy 的运行目录（cwd）设为当前工作区。
- Copilot CLI 的 base directory 设为当前工作区；应用另外提供受限的工作区文件工具。
- 对话记录按工作区分别保存。切换目录后加载该目录对应的会话，不混合不同项目的对话。
- Agent 正在执行任务时禁止切换或清除工作区，避免一个请求中途改变项目上下文。

Copilot 的工作区文件工具按当前权限开放：
- Browser only：不开放本地文件工具。
- Assisted：开放文件列表、文本读取和内容搜索。
- Allow all：在上述能力之外，开放工作区内文件写入。

CodeBuddy 继续使用其自身的内置文件和终端工具，并根据当前权限设置可用工具。没有选择工作区时，Agent 不会把应用用户数据目录误当作项目目录。

## 文件范围与边界

Copilot 的文件工具只接受相对路径，拒绝绝对路径、目录穿越和符号链接；不读取二进制文件或超过 256 KB 的文件。文件列表和搜索会跳过常见依赖、构建输出目录，并限制返回数量。写入只能针对工作区内普通文件，且目标父目录必须已存在。

**工作区是默认项目目录，不是操作系统级沙箱。** CodeBuddy 在 Allow all 权限下提供的 Bash 等内置工具仍具有 CLI 本身的本机访问能力；选择目录不会把这些进程限制在该目录中。需要严格隔离时，应使用操作系统级沙箱或独立容器，不能把 cwd 当作安全边界。

## 持久化

- 当前工作区路径：应用用户数据目录下的 `workspace-project.json`。
- Agent 会话：按规范化后的工作区路径生成独立标识，保存在 `agent-sessions/`。
- 工作区路径不会写入插件包，也不会通过插件配置同步。
